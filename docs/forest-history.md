# History

Ctrl+H opens History. It holds settled trees, grouped by the local day they were settled, newest first. Day names stay English. A shelf tree does not appear here.

Click a row or use Up and Down to select its miniature and capped preorder outline. Reopen, Enter and a double click resume the tree’s last page. An outline page opens that page. Find matches the tree’s title and sites. Escape clears Find first, then closes the forest. Older rows load sixty at a time.

The tree menu offers Reopen, Save for later, Rename and Delete. Save for later moves a tree to the shelf. Delete removes the tree’s visits, saved text, origins, events and download records immediately. Bookmarks and downloaded files remain. Deleted trees stop contributing suggestions.

The forest shows Deleted with Undo after a successful deletion. Undo restores the tree’s stored rows. It remains available until the next successful delete or the forest closes. Quitting loses Undo, so deletion needs no later cleanup. A failed restore keeps the record available for retry.
